# Games

**Play it here: https://latenightlabs.github.io/games/SpaceCadet/**

A turn-based space combat game that runs entirely in your browser. There's
nothing to install and no account, and saved games stay in your browser's
local storage. It works on desktop and on mobile.

## About this repo

This repo only hosts published builds, one folder per game.
`SpaceCadet/index.html` is the whole game, generated and pushed here
automatically from a private source repo after every change passes its
tests. Changes made to it here are overwritten by the next deploy.
